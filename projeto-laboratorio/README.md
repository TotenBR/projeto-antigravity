# Projeto Laboratório - Análise de Exames Sanguíneos

Este projeto é destinado a automatizar a leitura, análise clínica e geração de relatórios personalizados (PDF) para exames de sangue de pacientes.

## Estrutura do Projeto

- `data/`: Pasta destinada a armazenar os arquivos PDF de entrada (exames dos pacientes) e os PDFs de saída (relatórios gerados).
- `scripts/`: Scripts em Python para processamento de arquivos e chamadas de API.
- `requirements.txt`: Lista de dependências de Python necessárias para rodar o projeto.

## Instalação e Execução

1. Crie ou ative um ambiente virtual:
   ```bash
   python -m venv venv
   source venv/bin/activate
   ```
2. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```
