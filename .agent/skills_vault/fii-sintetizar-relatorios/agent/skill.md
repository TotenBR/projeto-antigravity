# Skill: Sintetizar Relatórios Financeiros
Description: Analisa múltiplos PDFs de fundos imobiliários, extrai pontos críticos e consolida em um único PDF executivo no HD.

## Diretrizes de Análise
Para cada PDF encontrado na pasta temporária, extraia:
1. **Principais Explicações**: Resumo da tese atual do fundo e alocação de ativos.
2. **Pontos Críticos**: Alertas de risco, inadimplência, vacância (se imobiliário), queda de rendimento ou alavancagem excessiva.
3. **Recomendações**: Visão analítica se o fundo mantém valor perante o cenário macroeconômico e se é hora de comprar, vender ou manter.

## Formatação do Output (PDF Final)
- O documento final deve ser gerado em formato PDF.
- Use uma estrutura de tópicos limpa e profissional.
- Inclua um "Sumário Executivo" destacando os 3 fundos com maior nível de alerta.
- Salve o arquivo final no caminho definido pelo usuário.
